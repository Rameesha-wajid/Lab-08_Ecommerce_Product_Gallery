
# E-Commerce Product Gallery

## Project Description
This project is a responsive E-Commerce Product Gallery
created using HTML and CSS.

## Technologies Used
- HTML
- CSS
- CSS Grid Layout

## CSS Concepts
- Display Grid
- Repeat()
- Auto-fit
- Minmax()
- Gap
- Hover Effects
- CSS Transitions

## Features
- Responsive product gallery
- Six product cards
- Product images and prices
- Hover animations
- Automatic column adjustment

## How to Run
1. Download or clone this repository.
2. Open Ecommerce Store.html in a web browser.
